# v1.1.0-rc.1 Release Candidate

This S16 candidate packages the shared public-company underwriting system for repeatable GitHub use. It adds one ticker-to-report command, environment diagnostics, exact dependency versions, offline CI, user documentation, private-data boundaries, and release diagnostics.

Formal partner-ready delivery through the new entry point requires a validated Gate 3 contract and an independent reproduction pass. A first public-only run may correctly stop with a diagnostic and analyst-input template.

This is not the final release. S17 true held-out testing, full regression, PDF QA, privacy scan, and final contract validation remain mandatory after code freeze.
